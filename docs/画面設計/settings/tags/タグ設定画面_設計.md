# 🎨 タグ設定画面 詳細設計

## 1. 画面概要

ユーザーが記事やメモに付与するタグを管理する画面。

- タグの追加・編集が可能
- タグ名と表示用カラーを設定

## 2. 主な機能

| 機能名       | 内容                                    |
| ------------ | --------------------------------------- |
| タグ一覧表示 | 既存タグの一覧を表示（タグ名・カラー）  |
| タグ追加     | 新しいタグを作成可能（タグ名 + カラー） |
| タグ編集     | 既存タグの名前・カラーを編集可能        |
| タグ削除     | 不要なタグを削除                        |
| 保存         | 編集内容をDBに保存（即時更新でも可）    |

## 3. UI構造イメージ

```text
タグ設定画面
--------------------------
[タグ名] [カラー] [編集] [削除]
[タグ名] [カラー] [編集] [削除]
...

[新しいタグ名入力] [カラー選択] [追加ボタン]
```

## 4. API連携

| 操作         | Mutation / Query             | 内容                     |
| ------------ | ---------------------------- | ------------------------ |
| タグ一覧取得 | `getTags(user_id)`           | ユーザーのタグ一覧を取得 |
| タグ作成     | `createTag(name, color)`     | 新規タグをDBに追加       |
| タグ更新     | `updateTag(id, name, color)` | タグ情報を更新           |
| タグ削除     | `deleteTag(id)`              | タグを削除               |

---

## 5. UI/UX仕様

- モバイル/PC両対応のレスポンシブデザイン
- カラー選択はカラーピッカーUI
- タグ追加・編集・削除はリアルタイム反映
- 削除時は確認ダイアログを表示
