# 🤖 AI APIキー管理画面 詳細設計

## 1. 画面概要

ユーザーがアプリで使用するAI（OpenAI）APIキーを確認・編集できる画面。

- APIキーは1つのみ登録可能

## 2. 主な機能

| 機能名              | 内容                                     |
| ------------------- | ---------------------------------------- |
| 登録済みAPIキー表示 | OpenAI APIキーの確認・マスク表示         |
| APIキー編集         | 新しいOpenAI APIキーを入力して上書き可能 |
| 保存                | 即時保存またはまとめて保存可能           |

## 3. UI構造イメージ

```text
AI APIキー管理
--------------------------
OpenAIキー: ******** [編集]
```

## 4. API連携

| 操作        | Mutation / Query             | 内容                     |
| ----------- | ---------------------------- | ------------------------ |
| APIキー取得 | `getApiKey(user_id)`         | 登録済みOpenAIキーを取得 |
| APIキー更新 | `updateApiKey(user_id, key)` | OpenAIキーを上書き保存   |

## 5. UI/UX仕様

- モバイル/PC両対応
- キーはマスク表示しセキュリティ配慮
- 編集時は入力欄に切り替えて上書き保存
