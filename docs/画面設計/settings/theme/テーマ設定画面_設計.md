# 🌗 テーマ設定画面 詳細設計

## 1. 画面概要

ユーザーがアプリの表示テーマを切り替えできる画面。

- ダークモード / ライトモード

## 2. 主な機能

| 機能名     | 内容                                   |
| ---------- | -------------------------------------- |
| テーマ切替 | ラジオボタンやトグルでテーマを切替可能 |

## 3. UI構造イメージ

```text
テーマ設定
--------------------------
[ ] ライトモード
[ ] ダークモード
```

## 4. API連携

| 操作           | Mutation / Query                  | 内容                     |
| -------------- | --------------------------------- | ------------------------ |
| テーマ設定取得 | `getUserTheme(user_id)`           | 現在のテーマを取得       |
| テーマ設定更新 | `updateUserTheme(user_id, theme)` | 選択したテーマのみを保存 |

## 5. UI/UX仕様

- モバイル/PC両対応
- テーマ変更は即時反映
