# 👤 プロフィール設定画面 詳細設計

## 1. 画面概要

ユーザーの名前とアイコンを確認・編集できる画面。

## 2. 主な機能

| 機能名       | 内容                           |
| ------------ | ------------------------------ |
| 名前編集     | ユーザー名を編集可能           |
| アイコン変更 | 画像アップロード・選択可能     |
| 保存         | 即時保存またはまとめて保存可能 |

## 3. UI構造イメージ

```text
プロフィール設定
--------------------------
名前: [ユーザー名]  [編集]
アイコン: [画像表示]  [変更ボタン]
```

## 4. API連携

| 操作             | Mutation / Query                   | 内容                 |
| ---------------- | ---------------------------------- | -------------------- |
| ユーザー情報取得 | `getUser(id)`                      | ユーザー情報取得     |
| ユーザー情報更新 | `updateUser(id, name, avatar_url)` | 名前・アイコンを更新 |

## 5. UI/UX仕様

- モバイル/PC両対応
- 変更時に即時反映されるように設計
