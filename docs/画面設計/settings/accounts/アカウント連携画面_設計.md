# 🔗 アカウント連携画面 詳細設計

## 1. 画面概要

ユーザーが連携している外部アカウントを確認・追加・解除できる画面。

- Google / GitHub / LINE / Xなど

## 2. 主な機能

| 機能名                 | 内容                           |
| ---------------------- | ------------------------------ |
| 連携済みアカウント表示 | 各プロバイダーの連携状態を表示 |
| アカウント連携追加     | 未連携プロバイダーを追加可能   |
| アカウント連携解除     | 連携済みアカウントを解除可能   |

## 3. UI構造イメージ

```text
アカウント連携
--------------------------
Google: 連携済み [解除]
GitHub: 未連携 [連携]
LINE: 未連携 [連携]
X: 未連携 [連携]
```

## 4. API連携

| 操作               | Mutation / Query                              | 内容                   |
| ------------------ | --------------------------------------------- | ---------------------- |
| アカウント連携追加 | `linkAccount(user_id, provider, provider_id)` | 新規連携               |
| アカウント連携解除 | `unlinkAccount(user_provider_id)`             | 解除                   |
| 連携情報取得       | `getUserProviders(user_id)`                   | ユーザーの連携状況取得 |

## 5. UI/UX仕様

- モバイル/PC両対応
- 解除時は確認ダイアログ表示
- 追加・解除は即時反映
