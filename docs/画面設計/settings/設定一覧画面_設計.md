# ⚙️ 設定一覧画面 詳細設計

## 1. 画面概要

ユーザーがアプリ全体の設定項目を一覧で確認し、各詳細設定画面に遷移できる画面。

## 2. 主な機能

| 項目             | 内容                                                |
| ---------------- | --------------------------------------------------- |
| プロフィール設定 | 名前・アイコン編集画面に遷移                        |
| APIキー管理      | APIキー管理画面に遷移                               |
| テーマ設定       | テーマ設定画面に遷移（ダークモード / ライトモード） |
| アカウント連携   | 外部アカウント連携画面に遷移                        |

## 3. UI構造イメージ

```text
設定一覧
--------------------------
[プロフィール設定] -> 画面遷移
[APIキー管理] -> 画面遷移
[テーマ設定] -> 画面遷移
[アカウント連携] -> 画面遷移
```

## 4. UI/UX仕様

- モバイル/PC両対応のレスポンシブデザイン
- 各設定項目をタップ/クリックすると該当の詳細設定画面に遷移
- 各画面での保存・操作は遷移先で実施
