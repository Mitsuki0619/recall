# 📄 記事詳細画面 詳細設計

## 1. 画面概要

記事情報、AI問題、メモをまとめて確認・操作できる画面。
記事情報はインライン編集、AI問題は詳細画面内で生成・編集可能。
メモは別画面で管理。

---

## 2. 記事情報編集

- 記事詳細画面内に表示
- **編集ボタン**でテキストフィールドに切り替え
- 編集後に**保存ボタン**で即時保存
- 編集箇所: タイトル、URL、概要

### UI例

```
記事タイトル: Article Title [編集]
URL: https://example.com [編集]
概要: この記事は〜… [編集]

編集モード:
記事タイトル: [__________] [保存] [キャンセル]
```

---

## 3 メモ表示

- 記事詳細画面ではメモの一覧を表示（タイトルのみ）
- 各メモに**編集ボタン**でメモ編集画面へ遷移
- 複数メモ対応

### UI例

```
メモ一覧:
- メモタイトル1 [編集]
- メモタイトル2 [編集]
- [+ 新規メモ作成]
```

---

## 4. AI問題管理

- 詳細画面内で生成ボタン・編集ボタンを配置
- **生成ボタン**: メモ内容を元にAIが問題を生成し表示
- **編集ボタン**: その場で問題文・選択肢・正解を修正可能
- 問題形式: 正誤 / 選択 / 記述
- 保存ボタンで即時DB反映

### UI例

```
AI問題:
1. 問題文 here
   正誤: [正しい] / [誤り]
   選択肢: A, B, C, D
   [編集] [削除]
   [生成]

編集モード:
問題文: [__________]
選択肢: [A:_____] [B:_____] [C:_____] [D:_____]
正解: [____]
[保存] [キャンセル]
```

---

## 5. API連携概要

| 操作         | Query/Mutation                                    | 内容                        |
| ------------ | ------------------------------------------------- | --------------------------- |
| 記事情報取得 | `getArticle(id)`                                  | 記事タイトル・URL・概要取得 |
| 記事情報更新 | `updateArticle(id, title, url, summary)`          | インライン編集保存          |
| AI問題生成   | `generateAIQuestion(article_id)`                  | メモ内容を元に問題生成      |
| AI問題更新   | `updateAIQuestion(id, question, options, answer)` | 編集内容保存                |
| メモ一覧取得 | `getMemos(article_id)`                            | 記事に紐づくメモ一覧        |

---

## 6. UI仕様

- 記事情報はインライン編集形式
- AI問題は生成・編集ボタンで即時操作
- メモは別画面に遷移して編集
- モバイル・PC両対応のレスポンシブデザイン
- 編集・生成失敗時はトースト通知

| AI問題生成失敗     | 「AI問題の生成に失敗しました」   |
| AI問題保存失敗     | 「AI問題の保存に失敗しました」   |
| メモ一覧取得失敗   | 「メモの取得に失敗しました」     |
| ネットワークエラー | 「通信エラーが発生しました」     |
