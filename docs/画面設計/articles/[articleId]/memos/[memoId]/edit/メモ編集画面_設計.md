# 📝 メモ編集画面 詳細設計

## 1. 画面概要

既存メモのタイトル・本文を編集可能。Markdownプレビュー対応。

## 2. 主な機能

| 機能名            | 内容                           |
| ----------------- | ------------------------------ |
| メモタイトル編集  | タイトルを変更可能             |
| メモ本文編集      | Markdown本文編集可能           |
| プレビュー        | 編集内容をリアルタイムで確認   |
| 保存 / キャンセル | 編集内容をDBに保存、または破棄 |

## 3. UI構造イメージ

```text
メモ編集画面
--------------------------
メモタイトル: [__________]
メモ本文(Markdown):
[____________________]
[プレビュー]
[保存] [キャンセル]
```

## 4. API連携

| 操作     | Mutation                         | 内容               |
| -------- | -------------------------------- | ------------------ |
| メモ更新 | `updateMemo(id, title, content)` | 既存メモをDBに保存 |
| メモ削除 | `deleteMemo(id)`                 | 必要に応じて削除   |
