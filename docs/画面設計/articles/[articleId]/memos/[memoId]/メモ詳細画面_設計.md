# 📝 メモ詳細画面 詳細設計

## 1. 画面概要

メモの内容を確認する画面。記事詳細画面からメモを選択して遷移。

## 2. 主な機能

| 機能名     | 内容                                     |
| ---------- | ---------------------------------------- |
| メモ表示   | タイトルとMarkdown本文をレンダリング表示 |
| 編集ボタン | 押下でメモ編集画面に遷移                 |
| 削除ボタン | 押下で削除確認後DBから削除               |

## 3. UI構造イメージ

```text
メモ詳細画面
--------------------------
メモタイトル: Title Here
メモ本文:
[Markdownレンダリング内容]
[編集] [削除]
```

## 4. API連携

| 操作     | Query/Mutation                   | 内容         |
| -------- | -------------------------------- | ------------ |
| メモ取得 | `getMemo(id)`                    | メモ内容取得 |
| メモ更新 | `updateMemo(id, title, content)` | 編集内容保存 |
| メモ削除 | `deleteMemo(id)`                 | メモ削除     |

---

## 5. 共通UI/UX仕様

- モバイル/PC両対応のレスポンシブデザイン
- Markdownプレビューはリアルタイム同期
- 保存・削除操作はトースト通知で成功/失敗を表示
- 削除操作は二段階確認ダイアログ付き
