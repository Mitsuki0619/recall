# 📝 メモ登録画面 詳細設計

## 1. 画面概要

記事に紐づく新規メモを作成する画面。Markdownで本文入力が可能。

## 2. 主な機能

| 機能名            | 内容                                         |
| ----------------- | -------------------------------------------- |
| メモタイトル入力  | メモのタイトルを入力                         |
| メモ本文入力      | Markdownで本文入力可能                       |
| プレビュー        | 入力中のMarkdown内容をリアルタイムプレビュー |
| 保存 / キャンセル | 作成内容をDBに保存、または破棄               |

## 3. UI構造イメージ

```text
メモ登録画面
--------------------------
メモタイトル: [__________]
メモ本文(Markdown):
[____________________]
[プレビュー]
[保存] [キャンセル]
```

## 4. API連携

| 操作     | Mutation                                 | 内容               |
| -------- | ---------------------------------------- | ------------------ |
| メモ作成 | `createMemo(article_id, title, content)` | 新規メモをDBに保存 |
