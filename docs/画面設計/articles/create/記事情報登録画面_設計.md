# 🖥 記事登録画面詳細設計

## 1. 画面概要

- **目的**：新しい記事をリーディングリストに追加する
- **主なユーザー操作**：
  - URL入力
  - タグやカテゴリの指定
  - OGPサムネイルの確認
  - 記事の保存

## 2. 主なUI要素

| 要素              | 種類                    | 説明                                |
| ----------------- | ----------------------- | ----------------------------------- |
| ヘッダー          | 固定                    | ロゴ、戻るボタン（トップ画面遷移）  |
| URL入力欄         | テキスト入力            | 記事のURLを入力                     |
| OGPサムネイル表示 | 画像                    | URLから自動取得したサムネイルを表示 |
| タイトル入力欄    | テキスト入力            | 自動取得したタイトルを編集可能      |
| タグ選択/入力     | チェックボックス + 入力 | 既存タグ選択 or 新規タグ作成        |
| カテゴリ選択      | ドロップダウン          | 既存カテゴリから選択                |
| 保存ボタン        | ボタン                  | 入力情報を保存、トップ画面に遷移    |
| キャンセルボタン  | ボタン                  | 入力を破棄、トップ画面に遷移        |

## 3. 操作・アクション

| 操作          | トリガー                    | 処理内容                                    | 遷移先     |
| ------------- | --------------------------- | ------------------------------------------- | ---------- |
| URL入力       | 入力完了 + フォーカスアウト | LambdaでOGP情報取得（タイトル、サムネイル） | 同画面     |
| タグ選択/入力 | 選択 or 入力                | タグリスト更新                              | 同画面     |
| カテゴリ選択  | ドロップダウン選択          | 選択値反映                                  | 同画面     |
| 記事保存      | 保存ボタンクリック          | GraphQL mutationで記事登録                  | トップ画面 |
| キャンセル    | キャンセルボタンクリック    | 入力破棄                                    | トップ画面 |

## 4. データ取得・更新フロー

```mermaid
flowchart TD
    Frontend[記事登録画面] -->|GraphQL query: fetchOGP(url)| Lambda[GraphQL API]
    Lambda -->|Fetch metadata| OGPService[(OGP取得)]
    Lambda --> Frontend

    Frontend -->|GraphQL mutation: createArticle(articleInput)| Lambda
    Lambda -->|Insert into Supabase| SupabaseDB[(Supabase PostgreSQL)]
    Lambda --> Frontend
```

- **取得データ例（OGP情報）**：

```json
{
  "title": "記事タイトル自動取得",
  "og_image_url": "https://s3.amazonaws.com/...",
  "description": "記事概要"
}
```

- **登録用入力例**：

```json
{
  "url": "https://example.com/article",
  "title": "記事タイトル",
  "og_image_url": "https://s3.amazonaws.com/...",
  "tags": ["Go", "AWS"],
  "category": "バックエンド"
}
```

## 5. 画面間遷移

```
[記事登録画面]
   ├─ 保存 → [トップ（記事一覧）]
   └─ キャンセル → [トップ（記事一覧）]
```

## 6. 補足・注意点

- OGP取得に失敗した場合はプレースホルダー画像表示
- タグ・カテゴリは既存データから選択可能、未登録の場合は新規作成
- バリデーション：URL必須、タイトル必須、タグ任意
- 画像はS3に保存する場合はPre-signed URLを使用して安全にアップロード
