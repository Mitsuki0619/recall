# 🔐 ログイン画面 詳細設計（SSOのみ）

## 1. 画面概要

ユーザーがアプリにアクセスするための認証画面。
Google / GitHub / X のSSOログインのみ対応。
シンプルかつレスポンシブなUIを想定。

---

## 2. 主な機能

| 機能名             | 内容                                 |
| ------------------ | ------------------------------------ |
| SSOログイン        | Google / GitHub / XでのOAuthログイン |
| エラーハンドリング | 認証失敗時にエラーメッセージ表示     |

---

## 3. 画面構成（構造イメージ）

```
───────────────────────────────
🔐 ログイン

SSOログイン
  [Googleでログイン] [GitHubでログイン] [Xでログイン]
───────────────────────────────
```

---

## 4. 操作仕様

### 4.1 SSOログイン

- 各ボタン押下でSupabase OAuthフローを開始
- 成功 → ユーザー情報取得後トップ画面へ遷移
- 失敗 → 「外部サービスとの連携に失敗しました」を表示

---

## 5. UI仕様

- モバイル／PC両対応のレスポンシブデザイン
- SSOボタンは各サービスのブランドカラーとアイコンを表示

---

## 6. API連携概要（Supabase想定）

| 操作        | API                             | メソッド | 備考            |
| ----------- | ------------------------------- | -------- | --------------- |
| SSOログイン | Supabase Auth `signInWithOAuth` | GET/POST | OAuthフロー開始 |

---

## 7. エラーハンドリング

| 発生箇所           | 表示メッセージ                         |
| ------------------ | -------------------------------------- |
| SSO連携失敗        | 「外部サービスとの連携に失敗しました」 |
| ネットワークエラー | 「通信エラーが発生しました」           |
