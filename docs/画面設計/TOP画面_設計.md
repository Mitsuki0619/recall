# 🖥 トップ画面（記事一覧）詳細設計

## 1. 画面概要

- **目的**：登録済みの記事の一覧を確認し、新規記事登録や検索・フィルタリングを行う
- **主なユーザー操作**：
  - 記事の閲覧
  - 新規記事登録
  - 記事検索・タグ/カテゴリでフィルタ
  - 記事詳細画面への遷移

## 2. 主なUI要素

| 要素                            | 種類                            | 説明                                            |
| ------------------------------- | ------------------------------- | ----------------------------------------------- |
| ヘッダー                        | 固定                            | ロゴ、ユーザーアイコン（設定画面遷移）          |
| 検索バー                        | テキスト入力                    | タイトル/URL/メモ内容で検索                     |
| フィルタ                        | ドロップダウン/チェックボックス | タグ選択、既読/未読、カテゴリ選択               |
| 記事カード                      | リスト表示                      | タイトル、OGPサムネイル、ドメイン、更新日、タグ |
| 記事クリック                    | カード全体                      | 記事詳細画面に遷移                              |
| 新規記事ボタン                  | 固定or浮動                      | 記事登録画面に遷移                              |
| ページネーション/無限スクロール | 表示制御                        | 記事の表示件数制御                              |

## 3. 操作・アクション

| 操作         | トリガー                    | 処理内容                              | 遷移先       |
| ------------ | --------------------------- | ------------------------------------- | ------------ |
| 記事検索     | キーワード入力 + 検索ボタン | GraphQLで記事一覧取得（フィルタ適用） | 同画面       |
| フィルタ適用 | タグ/カテゴリ選択           | GraphQLクエリで絞り込み               | 同画面       |
| 記事クリック | カードクリック              | 記事詳細取得                          | 記事詳細画面 |
| 新規記事登録 | ボタンクリック              | 記事登録画面表示                      | 記事登録画面 |
| 記事更新表示 | 定期/更新ボタン             | 最新情報取得                          | 同画面       |

## 4. データ取得・更新フロー

```mermaid
flowchart TD
    Frontend[トップ画面] -->|GraphQL query: getArticles(filters)| Lambda[GraphQL API]
    Lambda -->|Fetch from Supabase| SupabaseDB[(Supabase PostgreSQL)]
    Lambda --> Frontend
```

- **取得データ例（記事カード）**：

```json
{
  "id": "123",
  "title": "公式ドキュメントタイトル",
  "url": "https://example.com",
  "og_image_url": "https://s3.amazonaws.com/...",
  "tags": ["Go", "AWS"],
  "updated_at": "2025-10-12T00:00:00Z"
}
```

## 5. 画面間遷移

```
[トップ（記事一覧）]
   ├─ 記事カードクリック → [記事詳細]
   └─ 新規記事ボタンクリック → [記事登録]
```

## 6. 補足・注意点

- **無限スクロール or ページネーション** は記事数増加を見据えて設計
- **OGP画像キャッシュ** は S3 + Pre-signed URL で配信
- **検索・フィルタ** は軽量クエリ優先（TOP画面用は最小限情報）
- **アクセシビリティ**：キーボード操作・スクリーンリーダー対応を想定
